# 🔗 Slink — Link Management Platform

> Plataforma SaaS para armazenamento e acesso centralizado de links, desenvolvida do zero e em produção.

---

## 🚀 Acesse

**[slink-s.vercel.app](https://slink-s.vercel.app)**

---

## 📌 Sobre o projeto

Slink é uma plataforma web para organizar e acessar seus links de forma centralizada. Em vez de manter links espalhados em bloco de notas, favoritos ou conversas de WhatsApp, o Slink reúne tudo em um só lugar, acessível de qualquer dispositivo.

O projeto foi idealizado, desenvolvido e publicado de forma independente, com foco em uma experiência de usuário simples e funcional. Está em produção com usuários ativos e monitorado via Google Analytics.

---

## ✨ Funcionalidades

- ✅ Cadastro e autenticação de usuários
- ✅ Adição, e remoção de links
- ✅ Interface responsiva, funciona em desktop e mobile
- ✅ Persistência de dados em tempo real com Firebase
- ✅ Monitoramento de acessos via Google Analytics
- ✅ Deploy contínuo na Vercel

---
